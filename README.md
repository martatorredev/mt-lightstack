# MT Lightstack

MT Lightstack is a lightweight WordPress block theme focused on performance, sustainability, privacy, and accessibility.

> [!NOTE]
> MT Lightstack is currently under active development and is not ready for production use.

## Principles

MT Lightstack is built around a small set of principles:

- **Lightweight by default** — keep frontend assets and markup as small as reasonably possible.
- **Core-first** — use WordPress Core features and blocks instead of unnecessary custom code or dependencies.
- **Privacy by default** — no tracking and no external requests introduced by the theme.
- **Accessibility by design** — accessibility is considered throughout design and development.
- **Sustainable by design** — reduce unnecessary data transfer, processing, and dependencies.
- **No custom frontend JavaScript by default** — JavaScript is only added if there is a clear need that cannot be met by WordPress Core.

## Requirements

- WordPress 7.0 or later
- PHP 7.4 or later

## Development

The theme is being developed and tested with the WordPress Theme Review requirements in mind.
